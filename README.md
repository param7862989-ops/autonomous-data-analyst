# Autonomous Data Analyst

A full-stack AI engineering application that autonomously analyzes user-provided datasets through natural-language questions, controlled analytical tools, multi-step agentic workflows, and interactive visualizations.

## Planned Stack

- Frontend: Next.js, React, Tailwind CSS
- Backend: FastAPI, Python
- Data Analysis: Pandas
- Database: PostgreSQL
- AI: LLM API, structured outputs, tool calling
- Agent Orchestration: LangGraph
- Visualization: Plotly
- Infrastructure: Docker
- Version Control: Git/GitHub
